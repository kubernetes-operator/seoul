추세 (findings over time)

점검 실행에서 나온 발견(finding) 건수를 날짜별로 보여줍니다(하루 여러 번 실행 시 합산). 그래프 위 범례로 각 선을 확인하세요.
구분 = 심각도별: 선 = 심각도(■심각 / ■경고 / ■정보), 값 = 해당 심각도 건수. "도메인" 선택으로 특정 도메인만 볼 수 있습니다.
구분 = 도메인별: 선 = 도메인 하나(색상별), 값 = 그 도메인의 전체 발견 건수. 이 모드에서는 모든 도메인을 함께 표시하며 "도메인" 선택은 무시됩니다.
가로축 = 날짜, 세로축 = 건수(낮을수록 좋음).

부하 테스트

이 기능은 기본적으로 비활성화되어 있습니다. 활성화하려면 배포자가 MONITOR_LOADTEST_ENABLED=true로 ConfigMap을 수정하고 파드를 재시작해야 합니다 (deploy/README.md 참고).

실제 트래픽을 발생시킵니다. 대상은 사전 허용된 네임스페이스/서비스로만 제한되며(외부 URL 불가), GET 요청만 지원하고, 동시에 하나의 부하 테스트만 실행할 수 있습니다.
